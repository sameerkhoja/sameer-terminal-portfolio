# Sameer Khoja - Terminal Portfolio

An original dark-terminal portfolio built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Verify and build

```bash
npm test
npm run build
```

The production output is written to `dist/` and can be deployed to Vercel, Netlify,
Cloudflare Pages, or any static host.

## Edit content

Portfolio content lives in `src/data.ts`. Command metadata lives in
`src/lib/commands.ts`, and command output components live in
`src/components/CommandOutput.tsx`.

The source résumé included a phone number; the site intentionally omits it. The résumé
PDF is not bundled publicly for the same reason.
